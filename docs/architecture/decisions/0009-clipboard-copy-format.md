# ADR-0009: コピー形式は行選択 = 原文そのまま、セル範囲 = 可逆な quoted TSV とする

- 状態: 採用済み（Accepted）
- 日付: 2026-08-02
- 管理責任者: リポジトリメンテナー

本 ADR の状態は、この変更が `main` へマージされた時点で採用済みになります。暫定仕様の裁定であり、利用者の実運用確認（貼り付け先の表計算ソフトでの取り回し）により見直し得ます。

## 背景

P10（クリップボードコピー）で、原文にタブ・改行が含まれる場合の出力形式が未決だった（`LOG-024` の原文保持と、表計算ソフトへの貼り付けやすさ（4.5 暫定方針）の競合）。当時の計画正本（P10 クリップボードコピー）が推奨案を示していた。

## 決定

計画正本の推奨案を採用する。

- **行（論理ログ項目）選択**: 原文をそのままコピーする（内部のタブ・改行を保持。項目間は改行区切り）
- **セル範囲選択**: 可逆な quoted TSV（タブ・改行・二重引用符を含むセルを二重引用符で囲み、セル内の二重引用符は重ねる）
- バックスラッシュによる `\t` / `\n` への置換は採らない（可逆でないため）
- **初期リリースでは Unicode プレーンテキスト（CF_UNICODETEXT）のみを載せる。** HTML Clipboard 形式の併載は、quoted TSV で不足が確認された場合の拡張とする（複数形式のバッファ会計の複雑さを初期リリースで負わない判断）
- 上限判定（`COPY-004`）は正準のプレーンテキストの UTF-8 換算で行い、**上限ちょうどは許可・超過のみ拒否**（`COPY-005`）。拒否時はクリップボードを変更しない
- 表示外の範囲を含む選択の量算出は、行数（索引から即時）→ 超過なら即拒否、行数内なら本文をストリーミングで換算し**上限超過を検知した時点で打ち切る**（非有界の作業を作らない）

## 結果

- 良い影響: 原文の可逆性が保たれ、パス等のバックスラッシュを含むログでも壊れない
- 悪い影響: quoted TSV を解釈しない貼り付け先ではセル内改行が崩れて見える（見直す条件）

## セキュリティとプライバシーへの影響

コピーは個人情報等の機密データが他アプリへ渡る経路であり、明示的な操作時だけに限定する（`COPY-006`、`SEC-004`）。形式の選択自体に追加の影響はない。

## 移行または切り戻し

コピー生成（P10）に閉じる。形式変更は貼り付け先の作業手順に影響するため、新しい ADR を要する。

## 検証

- P10 の受け入れ条件（境界値、往復変換、バックスラッシュ非置換、部分コピーなし）の単体テスト

## 見直す条件

- 利用者の貼り付け先で quoted TSV の取り回しに支障が確認されたとき（HTML Clipboard 併載を再検討）
