# コネクター契約

- 状態: 草案（Draft）
- 管理責任者: リポジトリメンテナー
- 最終更新日: 2026-08-15

## 目的

本書は将来構想の概念契約です。初期リリースと後続リリースの確定要件では、新しいデータ形式は内部モジュールとして追加し、第三者向けの外部プラグイン機構は設けないことが採用済みです（`EXT-001`〜`EXT-003`、`PROD-010`）。本書の内容は、それより先の拡張を検討する際の出発点であり、現行の実装義務を定めません。

コネクターは、データソース固有の接続・列挙・取得・解析を Hakutaku の共通境界へ橋渡しします。この文書は概念契約であり、特定の言語 API、ABI、プロセスモデル、プラグイン形式を確定しません。

## 責務

- コネクター自身と互換性情報を識別する
- 利用可能な能力と必要な設定を宣言する
- 接続プロファイルを検証し、合意された仲介方法に従って操作に必要な認証手段だけを利用する
- リソースを列挙、または利用者指定から解決する
- 読み取り要求をデータソース固有の操作へ変換する
- 項目（Item）、進捗、診断情報、終了状態を逐次返す
- データソース固有のペイロードと来歴を失わない
- キャンセル、タイムアウト、流量制御に応答する
- 秘密値を秘匿化してから境界外へ情報を渡す

## 責務に含めないもの

- UI の画面構造や表示構成要素の選択
- ワークスペース全体の永続化とデータソース間の相関
- 他のコネクターのライフサイクル管理
- 認証情報の独自な平文保存
- データソースへの作成、更新、削除操作

## ライフサイクル

概念上、次の状態を区別します。

1. **検出済み（Discovered）** — コネクターのメタデータを読み取れる
2. **設定済み（Configured）** — 必須の非秘密設定と認証情報への参照が揃っている
3. **検証済み（Validated）** — 接続条件を検証した。検証は必須接続を意味しない場合がある
4. **読み取り中（Reading）** — 一つ以上の読み取り操作が進行中
5. **停止処理中（Stopping）** — キャンセルまたは破棄を処理中
6. **停止済み（Stopped）** — 資源と秘密情報への参照を解放した

同一インスタンスの並行読み取り可否と再利用可否は、能力として明示します。

## リソースの検出

コネクターはリソースを列挙できる場合、少なくとも次を返す候補とします。

- コネクター内で安定したリソース識別子
- 利用者向けの表示名と種類
- 親子関係またはパス（存在する場合）
- 利用可能な能力
- アクセス失敗や省略された範囲を表す診断情報

全件列挙が高コストまたは不可能なデータソースでは、検索、遅延展開、利用者による識別子指定を許容します。

## 読み取り要求

共通要求に含める候補:

- 対象リソース
- スナップショット、ストリーム、定期取得の更新モデル
- 時刻、位置、件数などの取得範囲
- データソース側で評価するクエリ、絞り込み、並べ替え
- ページサイズ、バッファー、最大結果数などの安全制限
- タイムアウト、キャンセル、再試行方針
- スキーマまたは未加工ペイロードの希望

コネクターが無視、変更、部分適用した条件は、結果とともに明示します。

## 項目の共通形式（Item envelope）

共通包絡形式（envelope）の最小候補を以下に示します。名前と必須性は ADR で確定します。

| フィールド | 目的 |
| --- | --- |
| `source` | 接続元を識別する。認証情報を含めない |
| `resource` | データソース内の取得対象を識別する |
| `identity` | 再取得時の同一性を示す候補。保証レベルを併記する |
| `eventTime` | データソースが示す出来事の時刻。意味、タイムゾーン、精度を[時間モデル](../domain/time-model.md)に従って保持する |
| `observedTime` | Hakutaku が項目を観測した時刻。出来事の時刻の代用にしない |
| `sequence` | 順序を示すデータソース固有、または取得内の位置 |
| `metadata` | 検索・相関に使える共通属性 |
| `payload` | データソース由来の内容。可能な限り忠実に保持する |
| `schema` | 固定、宣言、推論など構造情報への参照 |
| `provenance` | クエリ、範囲、変換など結果の来歴 |

包絡形式への正規化で失われる情報がある場合、未加工表現または損失の診断情報を提供します。

## 機能の宣言

能力の候補:

- リソースの検出と検索
- スナップショット、ページ分割、ストリーミング、定期取得
- サーバー側のクエリ、絞り込み、並べ替え
- スキーマの検出と変更通知
- 安定した同一性、順序付け、再開カーソル
- 見積もりと進捗
- 未加工表現
- 並行読み取り

真偽値だけでなく、上限、制約、意味の差異を表現できることが必要です。未対応の能力をアプリケーション中核が推測して呼び出してはいけません。

## クエリ、フィルター、検索の意味

- データソースへ渡す条件とビューアー内で評価する条件を区別する
- コネクターは適用した条件、適用しなかった条件、近似評価を報告する
- 入力は信頼せず、パラメーター化や許可リストなど、データソースに適した安全策を使う
- 読み取り専用であることを構文だけに依存せず、最小権限とデータソース側の制限を併用する

## ページ分割とストリーミング

- ページトークンまたはカーソルの有効範囲と再利用可否を明示する
- 順序が不安定な場合、重複・欠落の可能性を診断情報で示す
- ストリームには流量制御、バッファー上限、停止方法を定義する
- 再開が不可能な場合、再接続時の開始点を利用者へ示す
- 正常終了、キャンセル、タイムアウト、切断を異なる終了状態として返す

## キャンセルとタイムアウト

- アプリケーション中核からのキャンセルを速やかに受け取り、データソースの操作とコネクター内処理へ伝播する
- タイムアウトがどの区間に適用されたかを診断情報に含める
- 停止後に認証情報、接続、ファイルハンドル、バッファーを解放する
- 強制停止が必要な場合のデータ損失とデータソース側への影響を説明する

## エラーの分類

最低限、次を機械的に区別できるようにします。

- `configuration`
- `authentication`
- `authorization`
- `not-found`
- `unsupported`
- `timeout`
- `cancelled`
- `rate-limited`
- `source-unavailable`
- `parse`
- `schema-changed`
- `resource-exhausted`
- `internal`

診断情報は、安全なメッセージ、再試行可能性、影響範囲、原因の連鎖、利用者が取れる対処を持つ候補です。

## 観測性と秘密情報

- ペイロード本文、認証情報、接続文字列、認可ヘッダーを既定で記録しない
- データソースが返したエラーに秘密情報が含まれる前提で秘匿化する
- コネクター、操作、リソースを相関できる非秘密の識別子を使う
- デバッグ用診断情報の有効化では、収集範囲と保存先を事前に示す
- 仲介された認証手段は必要期間だけ保持し、表示用モデルへ渡さない

## 互換性とバージョン管理

次を独立してバージョン管理できる必要があります。

- コネクター契約
- コネクター実装
- 接続プロファイルのスキーマ
- 項目と診断情報の包絡形式
- データソース製品とプロトコルの互換性

互換性ポリシーは実装モデル決定時に ADR で確定します。

## 適合性テスト候補

- 能力の宣言と実際の振る舞いが一致する
- キャンセル、タイムアウト、部分的な失敗で資源を解放する
- 認証情報と既知の機密値が診断情報に現れない
- ページとストリームの重複・欠落条件を説明できる
- 不正、巨大、深い、遅い入力に安全に失敗する
- データソースへの書き込み操作を行わない
- 未加工ペイロードと来歴を検証できる

## 未決事項

以下は将来構想に関する未決事項であり、現行リリースの実装判断を妨げない。

- コネクターをライブラリ、プロセス、サービスのどれとして配布するか
- 契約と包絡形式の具体的な型・直列化方式
- 隔離、資源上限、署名・信頼モデル
- コネクターの信頼レベル、権限申告、利用者同意、認証情報仲介の方式
- 同一性と順序付けの保証レベル表現
- タイムゾーン、精度、時刻ずれ、遅延到着を含む時間モデルの具体化
- 秘匿化規則をアプリケーション中核とコネクターのどちらが所有するか
- 適合性テスト一式の範囲
